Reminders when Stint is closed

Stint can't wake itself up, so a free scheduled job in your GitHub repo sends this phone a push at your reminder time. Stint then checks your goals and only nags you if one isn't done.

  1. Tap Make setup code below, then Copy.
  2. Open GitHub → New secret. Name it STINT_PUSH, paste the code as the secret, and press Add secret.
  3. Open GitHub → Actions → Daily goal reminder and press Run workflow. A test notification should arrive within a minute.

Keep this code private: it lets anyone who has it send notifications to this phone. Only paste it into the GitHub secret.

If you change the reminder time or which days your goals are on, make a new code and replace the secret. GitHub's timing can be up to about 30 minutes late.
